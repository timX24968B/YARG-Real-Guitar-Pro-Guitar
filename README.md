# YARG-Real-Guitar-Pro-Guitar
 - An implementation of Rocksmith Style Chord and Note Recognition for Pro Guitar Play
## Features
 - Can Plug in a Realtone cable to use a real guitar for Pro Guitar Tracks.
 - Includes an additional scanner to analyze the song and chart, get the tuning of the song, and write the tuning to the .INI file.
 - Entire Implementation is based off Rocksmith-like note and chord detection behavior, so the gameplay can be a bit overzealous with what counts for things such as chords.
 - This is still very much in development, and any assistance on this project would be welcomed.
